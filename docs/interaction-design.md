## 1. 设计原则

### 1.1 核心体验目标

| 原则       | 说明                                                             |
| ---------- | ---------------------------------------------------------------- |
| **可预测** | 每个操作都有即时、明确的反馈；用户能预判点击后的结果             |
| **宽容**   | 关键操作（删除、退出）有二次确认；表单保留输入，不因意外丢失数据 |
| **高效**   | 高频操作（创建发票、筛选搜索）步骤最少，快捷键支持               |
| **透明**   | 加载、空、错误状态明确告知用户当前发生了什么                     |

### 1.2 交互反馈分级

| 级别 | 反馈方式                 | 适用场景             |
| ---- | ------------------------ | -------------------- |
| 轻微 | Hover 变色、光标变化     | 按钮、链接、可点击行 |
| 中等 | Toast 提示、按钮 loading | 保存成功、操作反馈   |
| 强烈 | 弹窗确认、页面 loading   | 删除、退出、页面加载 |
| 阻断 | 全屏错误、路由拦截       | 无权限、页面未找到   |

## 2. 全局交互规范

### 2.1 加载状态

| 场景               | 组件                  | 行为                                           |
| ------------------ | --------------------- | ---------------------------------------------- |
| 页面首次加载       | `n-spin` + 骨架屏     | 内容区域显示 Skeleton，非全屏 spinner          |
| 列表数据加载       | `n-spin` + 骨架屏表格 | 表格行以灰色占位条展示，3-5 行                 |
| 按钮触发的异步操作 | 按钮 `loading` 态     | 按钮显示 spinner，禁用点击，操作完成后恢复     |
| 页面内局部刷新     | 仅更新区域 `n-spin`   | 不影响其他区域操作                             |
| 路由切换           | 导航完成后加载        | 不显示全屏 loading，新页面的 Skeleton 展示即可 |

#### 2.1.1 骨架屏规范

- 发票列表骨架：5 行表格行，每行 6 列，灰色圆角矩形占位
- 发票详情骨架：标题占位 + 信息区块占位（3 个矩形块）+ 表格占位（4 行）
- 仪表盘骨架：统计卡片 4 个 + 图表区域占位
- 表单骨架：表单标签 + 输入框占位，逐行排列

### 2.2 空状态

| 场景          | 插图              | 文案                               | CTA                                    |
| ------------- | ----------------- | ---------------------------------- | -------------------------------------- |
| 发票列表为空  | 空文件夹/文档插画 | "还没有创建发票"                   | "创建第一张发票"按钮 → `/invoices/new` |
| 搜索结果为空  | 搜索放大镜插画    | "未找到匹配的发票"                 | "清除筛选"文字链接                     |
| 仪表盘无数据  | 空图表插画        | "暂无数据，创建发票后即可查看统计" | "去创建发票"按钮                       |
| 客户列表为空  | 空名片插画        | "还没有添加客户"                   | "添加客户"按钮                         |
| 通知/消息为空 | 空铃铛插画        | "暂无通知"                         | 无 CTA                                 |

#### 2.2.1 空状态交互行为

- 空状态组件居中展示，带有 1 个插图（48-64px）、标题、描述、可选 CTA 按钮
- 当数据从无到有时，空状态组件以 fade 动画过渡到正常内容
- 搜索结果为空时，筛选栏保持可见，方便用户修改查询条件

### 2.3 错误处理

| 错误类型           | 展示方式                               | 用户操作                             |
| ------------------ | -------------------------------------- | ------------------------------------ |
| 网络断开           | Toast "网络连接失败，请检查网络后重试" | 自动重试（指数退避，最多 3 次）      |
| Firebase Auth 异常 | Toast 显示中文错误原因                 | 根据错误类型显示不同信息             |
| Firestore 读写失败 | Toast "数据操作失败，请稍后重试"       | 保留用户输入，不跳转页面             |
| 404 页面不存在     | 全屏 404 插画 + "页面不存在"           | "返回首页"按钮                       |
| 表单校验失败       | 行内红色提示文字                       | 对应字段标红，第一个错误字段自动聚焦 |
| 路由守卫拦截       | 自动跳转，无 UI 反馈                   | 静默跳转到登录页                     |

#### 2.3.1 Toast 规范

| 类型    | 图标       | 持续时间 | 使用场景             |
| ------- | ---------- | -------- | -------------------- |
| success | 绿色勾 ✓   | 3s       | 创建/更新/删除成功   |
| warning | 黄色三角 ⚠ | 5s       | 操作有副作用但未阻断 |
| error   | 红色叉 ✕   | 5s       | 操作失败             |
| info    | 蓝色 i     | 3s       | 一般提示             |

#### 2.3.2 网络重连

- 检测到网络断开时，在页面顶部显示全局 Banner："网络连接已断开，正在尝试重连…"
- 网络恢复后 Banner 自动消失，显示 Toast "网络已恢复"
- 重连成功后自动刷新 Firestore 数据（`onSnapshot` 会自动恢复）

### 2.4 操作确认

| 操作       | 确认方式        | 弹窗文案                                                                                     |
| ---------- | --------------- | -------------------------------------------------------------------------------------------- |
| 删除发票   | `n-dialog` 弹窗 | "确定删除发票 INV-xxxx？此操作不可撤销。" 按钮："取消" / "确认删除"                          |
| 删除客户   | `n-dialog` 弹窗 | "确定删除客户 XXX？如有关联发票，删除后发票中的客户信息不受影响。" 按钮："取消" / "确认删除" |
| 退出登录   | `n-dialog` 弹窗 | "确定退出登录？" 按钮："取消" / "确认退出"                                                   |
| 离开编辑页 | `n-dialog` 弹窗 | "当前发票尚未保存，确定离开？" 按钮："留在当前页" / "离开"                                   |

#### 2.4.1 弹窗行为

- 弹窗居中展示，半透明遮罩覆盖背景（不可点击背景关闭）
- 点击"取消"或按 ESC 关闭弹窗
- 确认按钮带有 loading 状态（删除操作可能需要等待 Firebase）
- 弹窗出现时聚焦"取消"按钮（安全默认）

### 2.5 防重复提交

- 所有表单提交按钮点击后立即进入 `loading` 状态并 `disabled`
- 按钮文案不变，右侧显示 spinner
- 操作完成后（成功或失败）恢复按钮状态
- 路由变化不会中断进行中的提交（组件卸载前等待 Promise resolve）

### 2.6 全局快捷键

| 快捷键     | 功能              | 适用页面        |
| ---------- | ----------------- | --------------- |
| `Ctrl + N` | 创建新发票        | 发票列表页      |
| `Ctrl + S` | 保存当前表单      | 创建/编辑发票页 |
| `Ctrl + D` | 保存为草稿        | 创建/编辑发票页 |
| `Ctrl + P` | 打印发票          | 发票详情页      |
| `Escape`   | 关闭弹窗/下拉菜单 | 全局            |
| `Ctrl + K` | 聚焦搜索框        | 发票列表页      |
| `/`        | 聚焦搜索框        | 发票列表页      |

## 3. 认证模块

### 3.1 登录页（`/login`）

#### 3.1.1 页面布局

```
┌────────────────────────────────────────────────────────┐
│  ┌──────────────────────┐  ┌────────────────────────┐  │
│  │   左侧面板            │  │   右侧面板              │  │
│  │   InvoiceFlow Logo   │  │   "欢迎回来"            │  │
│  │   "专业发票管理"      │  │   邮箱输入              │  │
│  │   功能列表            │  │   密码输入              │  │
│  │   统计数据            │  │   记住我 + 忘记密码     │  │
│  │                      │  │   [登录]               │  │
│  │                      │  │   去注册                │  │
│  └──────────────────────┘  └────────────────────────┘  │
└────────────────────────────────────────────────────────┘
```

#### 3.1.2 输入交互

| 字段   | 焦点行为                                         | 失焦校验           | 实时校验     |
| ------ | ------------------------------------------------ | ------------------ | ------------ |
| 邮箱   | 输入框边框高亮（primary 色），前缀图标变 primary | 失焦时校验邮箱格式 | 输入时不校验 |
| 密码   | 输入框边框高亮，显示/隐藏密码图标可见            | 失焦时校验非空     | 输入时不校验 |
| 记住我 | 点击 checkbox 切换选中状态                       | —                  | —            |

#### 3.1.3 表单交互流

**登录流程：**

```
用户输入邮箱密码 → 点击"登录"按钮
  → 按钮进入 loading 状态（禁用、显示 spinner）
  → 表单执行完整校验
    → 校验失败：第一个错误字段聚焦，显示行内错误
    → 校验通过：调用 Firebase Auth
      → 成功：自动跳转 /invoices
      → 失败：按钮恢复，Toast 显示错误原因
```

**错误场景：**

- 邮箱格式错误 → 行内显示 "请输入有效的邮箱地址"
- 密码为空 → 行内显示 "请输入密码"
- 邮箱未注册 → Toast "该邮箱尚未注册"
- 密码错误 → Toast "邮箱或密码错误"
- 网络异常 → Toast "网络连接失败，请稍后重试"

#### 3.1.4 状态转移

```
[初始] → 填写表单 → [填写中] → 点击登录 → [登录中] → 成功 → [跳转列表]
                                            ↓ 失败
                                        [显示错误] → 修改 → [填写中]
```

#### 3.1.5 微交互

- 登录成功时，按钮短暂显示绿色勾图标（200ms）后跳转
- "忘记密码？"链接：当前阶段显示但功能未实现，点击时 Toast "功能开发中"
- 页面加载时表单卡片从右侧滑入（translateX: 80px → 0, 300ms ease-out）
- 左侧面板在页面加载时从左侧滑入（translateX: -40px → 0, 400ms ease-out）

### 3.2 注册页（`/register`）

#### 3.2.1 页面布局

```
┌────────────────────────────────────────────────────────┐
│  ┌──────────────────────┐  ┌────────────────────────┐  │
│  │   左侧面板            │  │   右侧面板              │  │
│  │   InvoiceFlow Logo   │  │   "创建新账户"          │  │
│  │   "加入 InvoiceFlow" │  │   邮箱输入              │  │
│  │   三步引导            │  │   名称输入              │  │
│  │   免费注册标签        │  │   密码 + 确认密码       │  │
│  │                      │  │   同意协议 checkbox     │  │
│  │                      │  │   [注册]               │  │
│  │                      │  │   去登录                │  │
│  └──────────────────────┘  └────────────────────────┘  │
└────────────────────────────────────────────────────────┘
```

#### 3.2.2 输入交互

| 字段     | 焦点行为                | 失焦校验        | 实时校验                             |
| -------- | ----------------------- | --------------- | ------------------------------------ |
| 邮箱     | 边框高亮，前缀图标变色  | 邮箱格式校验    | 不实时校验                           |
| 名称     | 边框高亮                | 非空，1-50 字符 | 不实时校验                           |
| 密码     | 边框高亮，显示/隐藏切换 | 最少 6 位       | 输入时显示密码强度指示器（弱/中/强） |
| 确认密码 | 边框高亮                | 与密码一致      | 输入时实时比对，不一致立即显示提示   |

#### 3.2.3 密码强度指示器

| 条件                              | 强度 | 指示条颜色 | 文案     |
| --------------------------------- | ---- | ---------- | -------- |
| 仅长度 >= 6                       | 弱   | 红色       | 强度：弱 |
| 长度 >= 8 + 字母+数字             | 中   | 橙色       | 强度：中 |
| 长度 >= 10 + 大小写+数字+特殊字符 | 强   | 绿色       | 强度：强 |

指示器在用户开始输入密码后才显示，位于密码输入框下方。

#### 3.2.4 表单交互流

```
用户填写注册信息 → 点击"注册"按钮
  → 按钮进入 loading 状态
  → 表单完整校验
    → 校验失败：第一个错误字段聚焦，行内显示错误
    → 校验通过：调用 Firebase Auth createUser
      → 成功：Firestore 写入用户文档 → 跳转 /invoices
      → 失败：按钮恢复，Toast 显示错误
```

**注册失败场景：**

- 邮箱已被注册 → Toast "该邮箱已被注册"
- 密码强度不足 → Toast "密码长度至少 6 位"
- 网络异常 → Toast "网络连接失败，请稍后重试"

#### 3.2.5 状态转移

同登录页状态转移。

#### 3.2.6 微交互

- 注册成功后自动登录并跳转，不额外展示中间页
- 三步引导中的当前步骤高亮显示（第一个高亮为白色背景，其他为半透明）
- 与登录页保持一致的进入动画

- 点击遮罩或选择导航项后 Drawer 关闭
- Navbar 显示汉堡菜单按钮 + 页面标题

### 5.2 页面加载流

```
进入 /invoices
  → authStore 判断用户
  → invoiceStore.startListening(userId)
  → onSnapshot 触发 → loading = true
  → 骨架屏展示
  → 数据到达 → loading = false → 渲染表格
  → 数据为空 → 展示空状态
```

### 5.3 筛选栏交互

#### 5.3.1 状态筛选

- 使用 `n-button-group` 或标签按钮组
- 选项：全部（默认）、草稿、已发送、已付款、已逾期
- 点击切换筛选状态，按钮高亮选中项
- 筛选即时生效（依赖 computed 过滤，无网络请求）
- 当前筛选状态反映在 URL query 参数上：`/invoices?status=sent`

#### 5.3.2 搜索框

- 占位符："搜索发票编号或客户名称…"
- 使用 `n-input` 的 `search` 类型（带搜索图标）
- 输入时防抖 300ms，防抖期间不清空搜索结果
- 清除按钮：出现文字时显示，点击清空输入并恢复列表
- 搜索和筛选同时生效（筛选结果中搜索）

**搜索交互流：**

```
用户输入文字 → 300ms 防抖 → 更新 searchQuery → filteredInvoices 重新计算 → 表格更新
用户清空文字 → 立即更新 searchQuery（无需防抖） → 表格恢复
```

#### 5.3.3 排序

- 下拉选择器，选项：创建时间（默认）、到期日期、金额
- 默认降序，点击排序字段旁的箭头可切换升序/降序
- 排序在当前筛选+搜索结果上进行（前端排序）

### 5.4 表格交互

#### 5.4.1 行交互

| 交互         | 行为                                                |
| ------------ | --------------------------------------------------- |
| Hover 行     | 背景色变为 `--color-hover`（浅灰），cursor: pointer |

#### 5.4.2 操作按钮

| 编辑 | 铅笔图标   | 仅 draft 状态显示且可点击；其他状态灰色不可点击，tooltip "仅草稿可编辑" |
| 删除 | 垃圾桶图标 | 点击弹出确认弹窗                                                        |

**交互行为：**

- 图标按钮 hover 变色
- 按钮点击区域至少 32x32px（Fitts 定律）
- 编辑按钮在非 draft 状态时视觉置灰，但仍响应用户点击，显示 tooltip 提示

#### 5.4.3 状态标签交互

每个行的状态列渲染 `InvoiceStatusBadge` 组件：

| 状态    | 颜色    | 背景色  | 图标     |

- 标签为圆角 Pill 形状，文字居中
- overdue 标签可闪烁动画（当为自动逾期时），吸引用户注意

### 5.5 空状态

见「2.2 空状态」规范。额外行为：

- 空状态展示时页面标题和筛选栏仍然保留

### 6.2 表单初始化

#### 6.2.1 创建模式（`/invoices/new`）

- 表单初始为空（所有字段默认值）
- 至少保留 1 行空商品明细行
- 税率默认从当前用户的 `defaultTaxRate` 读取
- 货币默认从当前用户的 `defaultCurrency` 读取
- 到期日期默认 = 今天 + `defaultDueDays`

#### 6.2.2 编辑模式（`/invoices/:id/edit`）

- 加载时从 Firestore 获取发票数据
- 加载过程显示骨架屏
- 所有字段预填已有值
- 商品明细表格预填已有行

### 6.3 客户信息区交互

| 字段 | 必填 | 校验规则         | 校验时机    |

| 名称 | 是   | 非空，1-100 字符 | 失焦 + 提交 |
| 邮箱 | 是   | 非空，邮箱格式   | 失焦 + 提交 |
| 地址 | 否   | —                | —           |
| 电话 | 否   | —                | —           |

- 所有输入框在失焦时校验，提交时再次全量校验
- 必填字段 label 前显示红色 `*`
- 校验失败时输入框变红，下方显示错误文案

### 6.4 商品明细表格交互

#### 6.4.1 行内编辑

每行四个单元格：

| 列   | 输入类型 | 行为                             |
| ---- | -------- | -------------------------------- |
| 描述 | 文本输入 | 自由输入，必填                   |
| 数量 | 数字输入 | 仅允许正整数，`min=1`            |
| 单价 | 数字输入 | 仅允许正数，精确到小数点后 2 位  |
| 金额 | 显示文本 | 自动计算 = 数量 × 单价，不可编辑 |

#### 6.4.2 实时计算

```
用户修改数量或单价 → 该行 total = quantity × unitPrice
  → 重新计算 subtotal = Σ total
  → 重新计算 taxAmount = subtotal × taxRate / 100
  → 重新计算 total = subtotal + taxAmount
  → 右侧金额汇总实时更新（输入即计算，无防抖）
```

#### 6.4.3 增删行

| 操作             | 行为                                              |
| ---------------- | ------------------------------------------------- |
| 点击"添加一行"   | 在表格末尾插入一个空行（描述=""，数量=1，单价=0） |
| 点击行末删除按钮 | 删除该行，如果只剩一行则按钮禁用（至少保留一行）  |
| 删除行动画       | 行 fade out (200ms) 后从 DOM 移除                 |

#### 6.4.4 行交互

- 输入框进入编辑状态时，该行背景色高亮
- 鼠标移出行时取消高亮（若该行无焦点输入框）
- Tab 键按单元格顺序切换焦点（描述 → 数量 → 单价 → 下一行描述）
- 在最后一行的单价字段按 Tab 自动添加新行并聚焦新行的描述字段

### 6.5 金额汇总交互

- 金额汇总卡片始终在右侧固定显示（滚动页面时随容器滚动？使用 `position: sticky`，top 为 Navbar 底部）
- 所有数值变化实时反映在汇总区（无防抖）
- 货币符号根据选择的货币类型变化（¥ / $ / €）
- 税率输入直接显示在汇总卡中，修改后立即重新计算

### 6.6 底部操作栏

#### 6.6.1 双按钮设计

| 按钮       | 类型                | 行为                             |
| ---------- | ------------------- | -------------------------------- |
| 保存为草稿 | 次要按钮（outline） | 状态设为 `draft`，保存后跳转列表 |
| 创建并发送 | 主要按钮（primary） | 状态设为 `sent`，保存后跳转列表  |

编辑模式下的按钮文本变化：

- "保存为草稿" → "保存修改"（仍保存为 draft）
- "创建并发送" → 隐藏（编辑模式下不可变更为 sent）

#### 6.6.2 提交交互流

```
点击任一按钮
  → 按钮 loading（disabled），不影响另一按钮
  → 全量表单校验
    → 校验失败：首错字段聚焦，行内错误展示
      → 按钮恢复，用户修正后再次提交
    → 校验通过：
      → createMode: Firebase addDoc → 跳转列表
      → editMode: Firebase updateDoc → 跳转详情页
```

### 6.7 离开提醒

- 当表单有未保存的修改时（`isDirty` 标志），尝试离开页面时弹出确认弹窗
- 检测方式：创建模式下表单任意字段非初始值；编辑模式下表单值与初始加载值不同
- 覆盖场景：
  - 点击浏览器的返回按钮
  - 路由导航到其他页面
  - 关闭浏览器 tab（`beforeunload` 事件）
- `beforeunload` 使用浏览器原生弹窗（无法自定义文案）

### 6.8 状态转移

```

   ↓                              ↓
[空表单加载]                   [加载已有数据]
   ↓                              ↓
[填写中 ←→ 实时计算]           [编辑中 ←→ 实时计算]
   ↓ 提交                         ↓ 提交
[校验] → 失败 → [填写中]        [校验] → 失败 → [编辑中]
   ↓ 成功                         ↓ 成功
[写入 Firestore]               [更新 Firestore]
   ↓                              ↓
[跳转列表页]                   [跳转详情页]
```

- Logo 上传：点击上传区域打开文件选择器，仅接受图片格式（jpg/png/svg）
- Logo 上传后显示预览，最大 2MB，超出提示

## 11. 动效与过渡规范

### 11.1 路由过渡

- 页面切换使用 Naive UI 的 fade-slide 过渡
- 持续时间：250ms ease-out
- 从右到左滑入（前进导航），从左到右滑出（返回导航）
- 通过 Vue Router 的 `<router-view>` 配合 `<transition>` 实现

### 11.2 列表过渡

- 增删列表项使用 `<TransitionGroup>`
- 新增项：fade in + slide down（300ms）
- 删除项：fade out + 宽度收缩（200ms）
- 列表排序/筛选变化：使用 FLIP 动画（First, Last, Invert, Play），避免突兀的位置跳跃

### 11.3 微交互动效

| 元素       | 触发动效                             | 持续时间  | 缓动函数    |
| ---------- | ------------------------------------ | --------- | ----------- |
| 按钮 hover | 轻微放大 (scale 1.02) + 阴影加深     | 150ms     | ease-out    |
| 按钮点击   | 回弹 (scale 0.97 → 1)                | 100ms     | ease-in-out |
| 卡片 hover | 上浮 (translateY -2px) + 阴影        | 200ms     | ease-out    |
| 弹窗出现   | 缩放 (scale 0.9 → 1) + 遮罩 fade in  | 200ms     | ease-out    |
| 弹窗关闭   | 缩放 (scale 1 → 0.9) + 遮罩 fade out | 150ms     | ease-in     |
| Toast 出现 | 从顶部滑入 (translateY -40px → 0)    | 250ms     | ease-out    |
| Toast 消失 | fade out                             | 200ms     | ease-in     |
| 复选框切换 | 勾选动画                             | 200ms     | ease-out    |
| 数字变化   | 计数动画 (count up)                  | 800ms     | ease-out    |
| 骨架屏     | 脉冲闪烁 (pulse)                     | 1.5s 循环 | linear      |
| 下拉菜单   | 展开 (scaleY 0 → 1, opacity 0 → 1)   | 150ms     | ease-out    |

### 11.4 过渡类名规范

```css
/* 路由过渡 */
.page-enter-active,
.page-leave-active {
  transition: all 0.25s ease-out;
}
.page-enter-from {
  opacity: 0;
  transform: translateX(20px);
}
.page-leave-to {
  opacity: 0;
  transform: translateX(-20px);
}

/* 列表过渡 */
.list-enter-active,
.list-leave-active {
  transition: all 0.3s ease-out;
}
.list-enter-from {
  opacity: 0;
  transform: translateY(-10px);
}
.list-leave-to {
  opacity: 0;
  transform: translateX(20px);
}
.list-move {
  transition: transform 0.3s ease-out;
}
```

## 12. 响应式断点与适配

### 12.1 断点定义

| 断点 | 范围          | 目标设备              |
| ---- | ------------- | --------------------- |
| xs   | < 480px       | 小屏手机              |
| sm   | 480 - 767px   | 大屏手机              |
| md   | 768 - 1023px  | 平板竖屏              |
| lg   | 1024 - 1199px | 平板横屏 / 小屏笔记本 |
| xl   | 1200 - 1599px | 桌面显示器            |
| xxl  | >= 1600px     | 大屏显示器            |

### 12.2 各页面适配策略

#### 12.2.1 登录/注册页

| 断点 | 适配行为                         |
| ---- | -------------------------------- |
| xl+  | 完整双栏布局                     |
| lg   | 双栏但左侧面板缩小 padding       |
| md   | 单栏：隐藏左侧面板，表单全宽居中 |
| < md | 单栏：表单全宽，padding 减半     |

#### 12.2.2 发票列表页

| 断点 | 适配行为                                  |
| ---- | ----------------------------------------- |
| xl+  | 完整表格 7 列                             |
| lg   | 表格 6 列（隐藏创建日期）                 |
| md   | 表格 5 列（隐藏创建日期+电话）            |
| sm   | 卡片式列表（每张发票一张卡片，非表格）    |
| xs   | 卡片式列表 + 简化操作（仅保留查看和删除） |

**移动端卡片式列表布局：**

```
┌──────────────────────────────────┐
│ INV-20240504-2837     [已发送]   │
│ 客户: xxx                       │
│ 金额: ¥ 530.00                  │
│ 到期: 2024-06-03                │
│ [查看] [编辑] [删除]             │
└──────────────────────────────────┘
```

#### 12.2.3 发票创建/编辑页

| 断点 | 适配行为                                        |
| ---- | ----------------------------------------------- |
| lg+  | 左右双栏（左：客户信息+明细表格，右：金额汇总） |
| md   | 上下单栏（金额汇总折叠到表格下方）              |
| < md | 单栏全宽，金额汇总以卡片形式嵌入底部            |
| sm   | 商品明细表格变为卡片式，每行一个商品卡片        |

#### 12.2.4 发票详情页

| 断点 | 适配行为                         |
| ---- | -------------------------------- |
| lg+  | 发票卡片居中展示，最大宽度 800px |
| md   | 发票卡片全宽，padding 减半       |
| < md | 全宽打印友好布局                 |

#### 12.2.5 仪表盘页

| 断点 | 适配行为                   |
| ---- | -------------------------- |
| lg+  | 4 列统计卡片，图表左右并排 |
| md   | 2 列统计卡片，图表上下排列 |
| < md | 1 列统计卡片，图表上下全宽 |

### 12.3 触控优化

| 设备类型 | 优化内容                                      |
| -------- | --------------------------------------------- |
| 触控屏   | 按钮最小高度 44px（WCAG 触控目标）            |
| 触控屏   | 表格行操作以长按/双指操作不适用，改用显式按钮 |
| 触控屏   | 下拉菜单展开后点击外部自动关闭                |
| 鼠标     | hover 交互正常显示                            |
| 鼠标     | 右键菜单不自定义（保持浏览器默认）            |
